# Follow-up work — `redis-grafana-integration`

This directory tracks work that came out of the
`redis-grafana-integration` change but was **deferred** to keep that
change focused. It is intentionally a separate folder from
`docs/sdd/redis-grafana-integration/` so the original change's scope
stays clean.

## Status legend

- `open` — known, not started
- `in-progress` — someone is working on it
- `ready-to-pr` — branch ready, awaiting review
- `merged` — landed
- `wont-fix` — explicitly rejected with rationale

## Priority

- **P0** — block follow-up features or risk data loss
- **P1** — quality / cleanup, should land within 1-2 weeks
- **P2** — nice to have, schedule when capacity allows
- **P3** — speculative, revisit quarterly

## Files

- [`issues.md`](issues.md) — 9 issues that were hit **and resolved** during
  the original change. Read this first when triaging a new bug report in
  this area; the resolution rationale lives here.
- [`prs.md`](prs.md) — 7 PR-shaped follow-ups with concrete scope, file
  list, acceptance criteria, and effort estimate. Pick from this when
  planning the next sprint.
